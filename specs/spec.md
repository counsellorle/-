# 企业级订单管理系统 需求规格说明书

---

## 1. 概述

本系统是一套基于 Web 的企业级订单管理系统，面向 **一个商家 + 多个客户** 的场景。客户可在系统中选择商品下单并支付，实时追踪订单进度；商家可管理商品、查看所有客户订单并推进订单状态。系统通过短信通知让双方及时获知订单变化。

---

## 2. 角色与权限

| 角色 | 权限说明 |
|------|----------|
| **客户** | 注册/登录；浏览商品；创建订单并支付；查看、修改、取消自己的订单（受状态限制）；查看订单进度、支付状态、预计完成时间、物流信息 |
| **商家** | 登录；管理商品（增删改）；查看所有客户的所有订单；修改订单状态（推进流程）；填写预计完成时间、物流单号；审核取消原因 |

**约束：**
- 客户只能看到本人提交的订单，无法看到其他客户的订单
- 商家可看到所有客户的订单，但不能代为创建订单
- 一个商家对应多个客户，单租户模式

---

## 3. 功能需求

### 3.1 用户注册与登录（客户）

- 注册：手机号 + 密码
- 登录：手机号 + 密码，或手机号 + 短信验证码
- 登录后进入订单列表页（默认展示本人订单）

### 3.2 商品管理（商家）

- 商家可发布商品，包含：商品名称、单价、商品描述（可选）
- 商家可编辑、下架/删除商品
- 客户下单时从商家发布的商品列表中选择

### 3.3 下单流程（客户）

- 客户从商品列表中选择一个或多个商品，指定每件商品的数量
- 填写收货地址
- 可添加备注（选填）
- 系统自动计算订单总金额
- 提交订单后进入支付环节，30 分钟内完成支付，超时自动取消

### 3.4 订单信息字段

| 字段 | 说明 | 填写方 |
|------|------|--------|
| 订单编号 | 系统自动生成，唯一 | 系统 |
| 商品明细 | 多个商品项，每项含商品名称、单价、数量 | 客户下单 |
| 订单总金额 | 系统自动计算 | 系统 |
| 收货地址 | 客户收货地址 | 客户 |
| 备注 | 客户留言（选填） | 客户 |
| 支付状态 | 未支付 / 已支付 / 已退款 | 系统 |
| 支付方式 | 微信 / 支付宝 / 银行转账 等 | 客户支付 |
| 订单状态 | 见 3.6 | 商家推进 |
| 预计完成时间 | 由商家在确认时设定 | 商家 |
| 物流单号 | 发货时填写 | 商家 |
| 取消原因 | 取消订单时必填 | 客户 |

### 3.5 支付

- 下单时立即发起支付
- 支付方式需记录
- 支付状态：**未支付** → **已支付**（支付成功）；**已支付** → **已退款**（取消退款）
- 下单后 **30 分钟** 内未支付，订单自动取消

### 3.6 订单状态流转

```
待支付 ──支付成功──▶ 已提交 ──商家确认──▶ 制作中 ──商家发货──▶ 已发货 ──商家完成──▶ 已完成
  │                    │                │
  └──超时自动取消──▶ 可取消/修改       可取消/修改（制作前）
```

**状态说明：**

| 状态 | 含义 | 可执行操作 |
|------|------|-----------|
| **待支付** | 订单已创建但未支付 | 客户支付；超时自动取消 |
| **已提交** | 支付成功，等待商家处理 | 客户取消（需填原因）；客户修改订单（地址、数量等）；商家确认 |
| **商家确认** | 商家已接单 | 客户取消（需填原因）；客户修改订单；商家填入预计完成时间，推进至制作中 |
| **制作中** | 订单生产中 | 商家发货（填入物流单号） |
| **已发货** | 已发货，含物流单号 | 客户查看物流；商家标记已完成 |
| **已完成** | 订单完成 | 只读，仅查看 |
| **已取消** | 订单已取消 | 只读，支付状态变为已退款 |

**约束：**
- 客户只能在"已提交"和"商家确认"状态下取消或修改订单（即 **制作前**）
- 进入"制作中"及之后状态，客户不可取消、不可修改
- 取消时必须填写取消原因
- 取消后系统自动退款，支付状态变为"已退款"

### 3.7 物流

- 订单状态为"已发货"时，显示物流单号
- 物流单号由商家在发货时填写

### 3.8 短信通知

以下节点向客户发送短信通知：

| 触发事件 | 通知内容 |
|----------|----------|
| 支付成功 | 订单提交成功 |
| 商家确认 | 订单已确认，预计完成时间 |
| 已发货 | 订单已发货，物流单号 |
| 订单完成 | 订单已完成 |
| 订单取消 | 订单已取消，退款信息 |

### 3.9 订单列表与搜索筛选

**客户端：**
- 默认展示本人所有订单，按创建时间倒序
- 支持按订单状态筛选（待支付、已提交、商家确认、制作中、已发货、已完成、已取消）
- 支持按日期范围搜索
- 支持按订单编号搜索

**商家端：**
- 默认展示所有客户的所有订单，按创建时间倒序
- 支持按订单状态筛选
- 支持按日期范围搜索
- 支持按订单编号搜索
- 支持按客户手机号搜索

---

## 4. 边界与约束

| 约束项 | 说明 |
|--------|------|
| 支付超时 | 下单后 30 分钟未支付，订单自动取消 |
| 取消条件 | 仅"已提交"和"商家确认"状态可取消，制作中及以后不可取消 |
| 修改条件 | 仅"已提交"和"商家确认"状态可修改 |
| 取消原因 | 必填 |
| 退款 | 取消后自动退款 |
| 预计完成时间 | 由商家在"商家确认"推进至"制作中"时填写 |
| 订单可见性 | 客户仅见本人订单，商家可见所有订单 |
| 单笔订单 | 可包含多个商品 |
| 商品来源 | 客户只能从商家已发布的商品列表中选择 |

---

## 5. 非功能需求

- 短信通知需及时送达
- 支付超时自动取消需准确计时（30 分钟）
- 订单编号全局唯一
- 所有金额以元为单位，精确到分（小数点后两位）
